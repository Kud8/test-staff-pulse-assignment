# Архитектура

## Слои
- `server/`: стандартный Node HTTP сервер, воспроизводимые данные в памяти. Без БД, авторизации и серверного фреймворка для одного endpoint.
- `shared/org.ts`: Zod схема и выведенный тип. Клиент проверяет недоверенный ответ, включая целостность графа.
- `src/api/org.ts`: HTTP, AbortSignal, контролируемые ошибки на русском: HTTP-статус, недоступный сервер, ответ не в JSON, некорректная структура. Отмена запроса пробрасывается как есть и не превращается в ошибку сети или формата.
- `src/api/query.ts`: единственный владелец server state — TanStack Query. staleTime 5000 мс, structural sharing сохраняет ссылки равных данных. Автоматический retry выключен: ошибка видна сразу, есть ручной повтор. По умолчанию устаревшие данные обновляются при mount/focus/reconnect; таймер polling отсутствует.
- `src/model/tree.ts`: чистое построение индексов дерева O(n), независимое от React.
- `src/model/aggregate.ts`: чистая агрегация снимка за один обход без рекурсии. Возвращает строки в порядке дерева с уровнем вложенности и индекс по id. См. [ADR 002](adr/002-aggregation.md).
- `src/model/table.ts`: чистые фильтр и сортировка готовых строк. Сортировка устойчивая, пустая эффективность всегда в конце. См. [ADR 003](adr/003-table-sorting.md).
- `src/ui/format.ts`: единственное место форматирования чисел, бюджета, эффективности и названия уровня — им пользуются и дерево, и таблица. Разряды разделяются вручную, потому что данные ICU различаются между средами, а формат фиксирован заданием.
- `src/ui/useTreeState.ts`: раскрытие, выделение и запрос на показ узла. Состояние общее для дерева и таблицы, поэтому выбор строки раскрывает предков и прокручивает дерево. В запросе есть признак перевода фокуса: он нужен, когда вызывающая сторона прячет элемент, на котором сейчас фокус.
- `src/ui/useDebouncedValue.ts`: задержка значения фильтра.
- `src/ui/OrgTree.tsx`, `src/ui/AnalyticsTable.tsx`: styled-components. Дерево — вложенные семантические списки с disclosure-кнопками на всю строку; таблица — обычная `table` с `th scope`, `aria-sort` и кнопками в заголовках. Нативные кнопки поддерживают Tab/Enter/Space. Не используется неполный ARIA tree widget. Обе панели показывают выделенный узел: дерево прокручивается к нему по запросу, таблица — по изменению выделения.
- `src/ui/Dashboard.tsx`: агрегация снимка через `useMemo`, общее состояние дерева, раскладка. От 1280 px обе панели показываются рядом, липнут под шапкой и прокручиваются внутри себя; ниже работает переключатель «Дерево / Таблица». Выбор строки в режиме переключателя прячет таблицу, поэтому дерево забирает фокус на выделенный узел. Ширина строк дерева зависит от ширины панели, а не экрана, поэтому используются container queries.
- `App`: состояния запроса и мемоизация модели по ссылке снимка. Экран загрузки и полноэкранная ошибка показываются, только пока данных нет. Если не удалось обновление, над последним снимком выводится предупреждение с повтором; дерево не размонтируется.

Поток: GET → unknown JSON → Zod/проверка графа → Query cache → индексы дерева → агрегаты снимка → фильтр и сортировка → UI. При удалении последнего подписчика Query отменяет потребляемый fetch signal. В StrictMode первый development запрос может быть отменён при проверочном размонтировании React.

Агрегаты пересчитываются только при новом снимке данных. Фильтр, сортировка, выделение и раскрытие ветвей их не трогают.

## Следующие этапы (не реализованы)
POLISH добавит версионированные патчи, обновление кэша и пересчёт сумм только по цепочке предков; BONUS — production-развёртывание и серверный адаптер LLM. Глобальный state manager не требуется.
