# Требования и план

Источник: staff_pulse_assignment.pdf, полностью прочитаны обе страницы, и уточнения пользователя. Прямых противоречий нет. Этапы строго последовательны; коммит и step/N только после приёмки. PDF, эта матрица (дополнительный документ вне PDF) и другие не запрошенные PDF документы не включаются в коммиты. Не выполнять push.

## План
1. FOUNDATION: Node API, контракт, кэш, дерево, состояния, основа интерфейса.
2. CORE: полная агрегация, аналитическая таблица, поиск, сортировка, связь с деревом.
3. POLISH: WebSocket, восстановление, инкрементальная агрегация и UX.
4. BONUS: Docker/Nginx, размер production, настоящий AI-поиск (провайдер уточняется перед интеграцией).

## Проверка CORE
- Typecheck и ESLint: успешно.
- Vitest: 88 тестов. Новое в этапе 2: агрегация на ручной фикстуре и на наборе API (суммы, взвешенное среднее вместо среднего средних, null при нулевой численности, порядок и уровень), фильтр (регистр, е/ё, пробелы, нет совпадений), сортировка каждого столбца в обе стороны с устойчивостью и пустыми значениями в конце, форматирование бюджета и эффективности, таблица с реальными значениями, клик/двойной клик/Enter по заголовку, debounce 250 мс на таймерах, выбор строки с раскрытием предков и прокруткой, счётчик вызовов агрегации.
- Production build: успешно, 385.06 kB, 119.75 kB gzip. Лимит 200 КБ gzip относится к этапу 4.
- Браузер 1440 px: дерево и таблица рядом, обе панели липкие и прокручиваются внутри себя, ширина строк дерева управляется container queries по ширине панели. Сортировка по бюджету кликом и двойным кликом дала ожидаемые строки, aria-sort меняется, двойной клик не выделяет текст. Фильтр «партнеров» применился примерно через 266 мс после последнего ввода и нашёл два подразделения с «ё». Выбор строки после «Свернуть всё» раскрыл предков, выделил узел в дереве и таблице и прокрутил область дерева без прокрутки страницы.
- Браузер 1024 и 390 px: переключатель виден, показывается одна панель, выбор строки возвращает к дереву и выделяет узел. На 390 px таблица прокручивается по горизонтали внутри панели, страница — нет.
- Ошибок и предупреждений console нет, атрибутов style в разметке нет.
- Ревью CORE (замечания пользователя B1–B5): исправлены потеря фокуса при скрытии панели таблицы на ширине меньше 1280 px (B1), расхождение разделителей разрядов между деревом и таблицей (B2), односторонняя связь панелей — теперь выбор в дереве прокручивает таблицу (B3), добавлен `touch-action: manipulation` на заголовок сортировки (B4). B5 (двойная сортировка внутри dblclick) признано допустимым и описано в ADR 003. На каждое исправление, кроме B4, сначала написан падающий тест; B4 проверен вычисленным стилем в браузере.
- Итог после исправлений: typecheck, lint, 91 тест и build успешно; в браузере фокус на 1024 px уходит на узел дерева, на 1440 px остаётся в таблице, выбор в дереве прокручивает таблицу к строке.
- Этап CORE реализован Claude Code по TDD: тесты написаны до кода, ожидаемые значения посчитаны вручную из формул генератора. Коммит и тег step/2 — только после приёмки.

## Проверка FOUNDATION
- Typecheck и ESLint: успешно.
- Vitest: 36 тестов (контракт и отказ от нормализации строк, целостность графа, кэш/время/ссылки, AbortSignal и отмена, состояния UI через настоящий API-клиент в jsdom, дерево с данными).
- Production build: успешно.
- Браузер: рабочий сценарий 1280 и 390 px, раскрытие/сворачивание, Enter/Space, выделение, focus; без горизонтальной прокрутки на 390 px и без ошибок console при чистой загрузке.
- В элементах приложения нет style-атрибутов. Единственный style вне приложения принадлежит служебному overlay браузера Codex.
- Loading/error/empty, повтор и сохранение дерева при ошибке фонового обновления покрыты тестами jsdom; ошибки HTTP, HTML вместо JSON, 204, сети и фоновый 502 проверены в браузере подменой ответа.
- Независимое ревью Claude Code: замечания (фоновая ошибка скрывала дерево, английские сообщения, нормализация строк, нет тестов дерева, выравнивание заголовка, favicon, `#src/*` в imports) исправлены Codex и перепроверены.
- Этап принят: коммит `step/1: FOUNDATION` с тегом step/1 на master, без push. PDF и эта матрица в коммит не включены.

### Замечания к FOUNDATION
Исправлены SVG-стрелки и вертикальное выравнивание; вся строка — disclosure-кнопка, выбор отмечен aria-current. Обновлён дизайн, добавлен sticky/blur header, удалено вводное описание. Правило собственных значений дерева сохранено, подписи уточнены. Проверены клики/Space и мобильное отображение.

По отдельному запросу пользователя в FOUNDATION добавлена анимация раскрытия: height 240 мс с CSS interpolate-size, fallback grid-template-rows; поворот SVG и затухание. Это только согласованная UX-доработка, остальные требования POLISH не начаты. Закрытые ветви inert/aria-hidden; prefers-reduced-motion отключает переходы. В браузере проверены закрытие/открытие и Tab, пропускающий скрытые команды.
